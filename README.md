# weFit Labs Investor Experience

This repository contains the **weFit Labs investor landing page** built with Vite + React + TypeScript. The full project lives in the [`wefit-investors`](./wefit-investors) directory with setup instructions, architecture notes, and development scripts.

## Quick start

```bash
cd wefit-investors
npm install
npm run dev
```

For more details, see [wefit-investors/README.md](./wefit-investors/README.md).
